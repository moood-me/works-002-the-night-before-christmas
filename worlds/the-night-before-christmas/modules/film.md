# film — фильм сцены кусками, для игры

Сцена-фильм режется на куски (beats). Игра запускает их по одному. Между кусками — выборы, мини-игры, реплики; сцена в это время живёт (дыхание, огонь, дождь) и держит последнюю позу куска.

```js
// script.js сцены ("modules": ["chrysalids", "film"] в scene.json)
scene.kit.film.beats(scene, {
  enter: { from: { fade: 1, david_a: -3 }, rows: [[0, 'fade', 0, 2], [1, 'david_a', 0, 3, 'inOut']] },
  ask: { after: 'enter', from: { … }, rows: [ … ] },
  ask_lie: { after: 'enter', from: { … }, rows: [ … ] }, // ветка
}, { film: ['enter', 'ask'] });
```

- **Ключ состояния `beat`.** Имя куска запускает этот кусок с начала. Когда кончилась последняя строка, сцена говорит `scene.tell('beat:<имя>')`. Игра ждёт этого (`g.beat` в коде игры).
- **`film` или ключа нет вовсе** — монтаж самой сцены: куски из `film` подряд. Его видит зритель мира. Поставьте в `scene.json` `"state": { "beat": "film", … }`.
- **`rows`** — строки как у `scene.play`: `[at | '+s', key, value, over?, ease?]`, `[at, fn]`, `[at, key, {turn}]`, `[at, [keys], {path}]`. Секунды — от начала куска.
- **`from`** — значения, с которых кусок начинается. Они ставятся сразу, если кусок идёт не после одного из `after` (сцену открыли на нём, или перед ним был другой). Так игра может начать с любого куска. Это склейка (`scene.cut`): люди сразу там, где `from` их ставит, — не идут туда шагами. `from` должен описывать всё, что кусок не ставит сам.
- **Новый кусок обрывает идущий:** его строки, которые ещё не начались, не начнутся. Начатые движения доходят. Если оборванный кусок есть в `after` нового, `from` не ставится: новый продолжает с того, что есть (ветка посреди куска — без прыжка). Строки оборванного куска, которые ещё не начались, новый должен выставить сам, если они нужны.
- **Ветки** — отдельные куски с тем же `after`.
- **Удержание** — после куска значения стоят; люди модуля `chrysalids` дышат сами. Если поза должна жить заметнее (плач, дрожь), это часть позы, а не новый кусок.
