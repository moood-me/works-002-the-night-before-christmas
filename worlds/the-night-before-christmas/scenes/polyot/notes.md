# Полёт (`polyot`)

Пространство полёта, пока без людей: поле за плетнём Пацюка, откуда взлетают, и ночное небо над
землёй, проплывающей внизу, — Диканька, степь с хуторами и стогами, лес, сёла, огни Петербурга, дворец
с горящими окнами; справа всю дорогу — река во льду. Тот же язык, что в «Диканьке»: простые объёмы,
снег, сине-чернильная ночь, тёплые окна, месяц, простор.

## Ключи

| ключ | что | начало |
| --- | --- | --- |
| `progress` 0…1 | путь: 0 — поле (Диканька впереди), 1 — над дворцом. Земля приходит к камере на `ROUTE` = 6 км | 0 |
| `camera_h` | высота камеры (ключ движка). 0 — на поле, у глаз; в полёте ≈110 м. Взлёт (`takeoff`) — это он, 0 → 110 | 0 |
| `bank` −1…1 | крен: в воздухе (`camera_h` > 20) сносит курс вбок — `camera_x` (±260 м) | 0 |
| `climb` −1…1 | набор/снижение: в воздухе меняет `camera_h` (40…240 м) | 0 |
| `moon` 0…1 | месяц и его свет | 1 |
| `moon_near` 0…1 | месяц рядом: огромный серп сбоку от летящих, свет сильнее | 0 |
| `stars` 0…1 | звёзды; первыми гаснут тусклые | 1 |
| `dawn` 0…1 | рассвет: небо розовеет справа, звёзды гаснут одна за другой, месяц бледнеет до серпа без сияния | 0 |
| `at_<id>` | где сейчас вещь пути (метры). Их ставит скрипт из `progress` — это механика, не трогать | — |

`dawn` — ещё и направление (ползунок на сайте).

## Как устроена

- Камера `around` (взгляд вокруг, ±30°) поднимается `camera_h`. Плоскости — честная геометрия:
  снег (`ground1…5`) и река (`river1…5`) полосами по расстоянию (до 400 км, чтобы воздух густел над ними
  плавно). Дымка — движковая (`light.haze`, `hazeColor`).
- Земля приходит к камере: каждая вещь пути — карточка с `place.distance` = `at_<id>`, скрипт
  (`script.js`) ставит `at_<id>` = b − progress × ROUTE (`LAND`, `CLOUDS`, `FLOW` в `lib.js`).
- Вещь рисуется такой, какой её видно сейчас: её объёмы (хаты, срубы, ели, стога, кварталы, дворец)
  проецируются из глаза на высоте `camera_h` на карточку там, где она стоит (`card`). Видны только
  грани к глазу; окна — тёплые, с огоньком (`e.light`).
- Небо — полный круг (`around`): градиент, звёзды, месяц по пеленгу (`MOON_FAR` → `MOON_NEAR`).
- Облака — карточки на своей высоте (одни выше, другие ниже полёта), приходят вместе с землёй.

## Ждёт движка

- **Крен и тангаж камеры.** Горизонт не клонится: `bank` пока только сносит курс, `climb` — только
  меняет высоту.
- **`place` у плоскостей.** Плоскость стоит на месте, поэтому проплывают только вещи: снег везде
  одинаковый, река — прямая вдоль всего пути, ни полей, ни дорог, ни излучин.
- **Поднятая камера вне `around`.** В `walk`/`picture`/`overhead` карточка дальше 255 м (Z_FAR)
  сдвигается с высотой, как будто стоит на 255 м: дальняя земля съезжает вниз. Поэтому сцена в `around`,
  где карточки ставятся по настоящему расстоянию.
- **`reflect` у неба в `around`.** Не рисуется: лёд реки не отражает месяц и звёзды (лёд пока просто
  тёмный). Огоньки (`e.light`) у неба в `around` тоже не рисуются — звёзды не мерцают.
- **Дымка карточек со старта.** Движок дымит только плоскости; дальние сёла и лес на горизонте
  чётче, чем должны.
- **`hazeColor` по состоянию.** На рассвете даль уходит в ночную синь.
- **Поворот камеры для фильма (`camera_yaw`).** Домой (`home`) летят с `progress` от 1 к 0 — земля
  уходит назад; взгляд по ходу (на 180°) пока может повернуть только ключ, которого нет.
- В `around` плоскости рисуются в порядке списка, раньше всего стоящего: снег, потом река.
