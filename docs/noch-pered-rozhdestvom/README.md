# «Ночь перед Рождеством» — документация игры

Игра по повести Николая Гоголя на новом мире «Ночь перед Рождеством» (его ещё нет): тип bespoke, по образцу
«Падения дома Ашеров» (docs/usher/). Светлая комедия: украденный месяц, гости Солохи в мешках, полёт на чёрте к
царице, черевички.

- [design.md](design.md) — замысел: что переживает игрок, лейтмотив и атмосфера, чьими глазами, погружение, ход
  игры по главам с развилками, мини-игры, шкалы и цены, финал и концовки, стилистика, как делаем.
- [scenes.md](scenes.md) — сцены нового мира и куски их фильмов: что видно, ключи состояния, элементы для выбора,
  реплики; люди мира для модуля людей — контракт между сценами и кодом игры.
