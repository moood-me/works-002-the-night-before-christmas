# 2026-10-09 — Диканька на движке 2

Первая сцена, переписанная для движка 2: главная сцена мира «Ночь перед Рождеством» (`pavel/noch-pered-rozhdestvom`,
`scenes/main`), ветка мира `engine2-dikanka` (от `env/malay/three`). Что где в сцене — её `notes.md`.

## Как переписана

- `"engine": 2`, картины статичны (дневные цвета; ночь, рассвет, утро, метель — взглядами и светом), `e.t` нигде.
- Небо — три элемента неба: `sky` (свой шейдер: градиент, заря, солнце — цвета из ключей считает animate в
  униформы), `stars` (шейдер рисует звёзды сам: поля ячеек, мерцание у каждой своё, гаснут по одной — тусклые первыми,
  тонут в свете месяца, исчезают по следу метлы ведьмы), `moon` (слои ореол и серп, двигает animate; из трубы
  Солохи — по `e.point` устья на небе; дальний свет `from: "moon#moon"` идёт за ним).
- Искры на снегу — плоскость со своим шейдером; окна — слой `warm` + свет каждого окна, гаснут через `e.glow`;
  тополя — слой с ветром; дым, искры и сажа из труб, метель, искры звёзд за метлой — частицы.
- Новое по сценарию мира: ведьма (человек каста на метле — `witch_on: "broom#seat"`, полёт — кривая Катмулла — Рома
  одним `path`), месяц уходит в трубу Солохи и вылетает из неё с искрами, свеча в звезде колядников (`at:
  "parubok1#candle"` — точка части `zirka` каста: единственное изменение модуля `cast`), крупный план стены церкви
  (вставка, два чёрта — слои по `devil_face`).
- Фильм — куски-последовательности режиссёра в `lib.js` (`FILM`): witch, chub_out, lost, moonrise, kolyadka,
  farewell, dawn, morning; новый модуль мира `beats` (для сцен движка 2; у старых остаётся `film`) играет их по ключу
  `beat` для игры и как показ (`showcase.js`) со склейками, готовыми заранее.
- Игры: ни одна игра (`moood-me/pavel--game--*`) мир не использует; ключи, точки и id старой сцены сохранены с тем же
  смыслом (у `moon#moon` точку теперь отмечает animate; `blizzard_far`/`blizzard_near` — карточки — заменены частицами
  `blizzard_snow`; `beat` больше не начинается с `film`: вне игр сцену показывает `showcase`).

## Движок по ходу (найдено этой сценой, починено агентами движка)

Небо и вставки без слоёв, шейдера и свечений слоёв; дальний свет не шёл за точкой неба от animate; `e.point` неба;
свечения неба — света мира; `world.chain` до определения (рендер висел); объём воздуха поверх вставок; люди, глядящие на
точку элемента; свет в руках человека выпадал из списка. Открыто: `@moood/render` не рендерит показ (`--showcase`).

## Проверка

Рендеры `@moood/render` (SwiftShader, движок из рабочей копии) взглядов (ночь, метель без месяца, рассвет, утро,
крупный план) и каждого куска через `--set beat`, рядом со старым движком; два круга правок света по ним (свет движка 2
линейный — числа взглядов подобраны заново).
